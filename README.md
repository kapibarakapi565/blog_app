# Blog App

## 概要
Ruby on Railsで作成したブログアプリです。  
ユーザー登録・ログイン機能を実装し、投稿の作成や一覧表示ができます。  
また、Cloudinaryを利用した画像投稿機能にも対応しています。

---

## 機能一覧
- ユーザー登録 / ログイン（Devise）
- 投稿の作成・編集 / 一覧表示 / 削除
- 画像投稿機能（Cloudinary）
- プロフィールページ表示

---

## 使用技術
- Ruby
- Ruby on Rails
- MySQL（開発環境）
- PostgreSQL（本番環境 / Render）
- Devise
- Cloudinary
